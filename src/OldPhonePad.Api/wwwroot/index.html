Using it without the HTTP layer

This page is a wrapper. If you are on .NET, skip the network entirely and call the library directly — it has no dependencies and runs anywhere from .NET Framework 4.6.2 upward.

Install
dotnet add package OldPhonePad
Decode
using OldPhonePad;

OldPhone.OldPhonePad("4433555 555666#");
Handle bad input without exceptions
var result = OldPhonePadDecoder.Default
    .TryDecode(userInput);

if (!result.IsSuccess)
    return BadRequest(result.ErrorMessage);
